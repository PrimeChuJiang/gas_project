# .deepseek —— 我的记忆与对话存档

本目录由 AI（deepseek-v4-flash）独占维护与读取，用于跨会话记忆。

## 文件结构

| 文件 | 用途 |
|------|------|
| `AGENTS.md` | 我的身份与角色约束（每次会话必读的第一份文件） |
| `project_context.md` | 项目状态快照、路线图、已完成课程、待办遗留 |
| `teaching_method.md` | 教学法：如何提问、如何给思路、如何验证 |
| `sessions/*.md` | 每次会话的对话记录与要点（按日期命名） |

## 维护规则（我自己遵守）

1. 每次会话开始时：先读 `AGENTS.md` → `project_context.md` → `teaching_method.md`，
   再读最近一次的 `sessions/` 记录以获得上下文衔接。
2. 每次会话结束时：把本次对话的要点追加进 `sessions/`，并更新 `project_context.md`。
3. `project_context.md` 只反映**已验证/已落地**的事实，不记录未经证实的猜测。
4. 教学角色：只给思路、提问、设计方向、指坑，**不替用户写实现代码**（可给伪代码骨架）。
5. 用户代码的进度以其仓库内 DEVLOG.md 与 git 提交为准，本目录只是辅助记忆。

## 为什么用这些文件

- 单一大文件容易越写越长、检索成本高 → 按"身份 / 项目 / 方法 / 会话"四分。
- 会话记录是流水账，项目上下文是提炼后的状态——两者分开，避免互相污染。
